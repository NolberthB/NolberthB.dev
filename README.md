# NolberthB.dev

Minimal, single-page portfolio for **Nolberto Betancourt** — backend development, networking, and automation.

Built with [Astro](https://astro.build/). The site highlights selected projects, real-world experience, education, and contact information.

## Development

Requires Node.js 18+.

~~~bash
npm install
npm run dev
npm run build
npm run preview
~~~
